# Tier 1 screen recording script (about 2 minutes)

Before recording: run `npm run dev`, open http://localhost:5173, then go to
**Grown-ups → Overview → Reset to demo data** so the data matches this script. Record at
browser width 1280 px or wider.

| Time | Show                                                                             | Say                                                                                                                                                                                                  |
| ---- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00 | Start screen                                                                     | "LifeSync helps autistic learners practise real routines in a copy of their own world, then checks whether the skill works in real life."                                                            |
| 0:10 | Grown-ups → Wearable → **Use simulator**                                         | "We'll simulate a heart-rate wearable. A real Bluetooth strap works the same way."                                                                                                                   |
| 0:20 | Grown-ups → Routines → **Brush my teeth**, add a photo to step 1                 | "Teachers and parents build routines from photos of the learner's actual bathroom, bus stop or store."                                                                                               |
| 0:35 | Logo → **Sam** → **Pay at the grocery store**                                    | "This is the learner's view: a First/Then board, then one step at a time."                                                                                                                           |
| 0:45 | Tap **Start**, tap a wrong choice, then the right one                            | "There's no 'wrong' message. The other choice fades and the right one is outlined. That's errorless learning."                                                                                       |
| 1:00 | Open **♥** bottom-left, press **Spike**, wait                                   | "If heart rate stays high, LifeSync pauses the routine and opens a calm screen with the learner's own calming tools."                                                                                |
| 1:15 | Switch Breathe → Squeeze, press **I'm ready** after it unlocks, press **Settle** | "When they're ready, they carry on from the same step."                                                                                                                                              |
| 1:25 | Finish the routine                                                               | "Rewards match the learner. Sam gets his favourite trains."                                                                                                                                          |
| 1:35 | Grown-ups → **Progress data** → Sam                                              | "The team sees sticking points, help levels per step and how help fades over time."                                                                                                                  |
| 1:45 | Scroll to **Brush my teeth**: the yellow **Generalization gap** banner           | "And this is the key part: Sam has mastered tooth-brushing in the app, but the real-world check-ins show he still needs help at home. That's the generalization gap, and LifeSync makes it visible." |
| 1:55 | **Log a real-world try**, then **Export practice CSV**                           | "Parents log real-world tries, and everything exports for the IEP meeting."                                                                                                                          |
